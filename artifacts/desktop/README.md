# НеЗабудка — Десктоп приложение

Electron-приложение с локальной SQLite базой данных. Работает **без интернета**, данные хранятся на компьютере пользователя.

---

## Как получить .exe через GitHub Actions (рекомендуется)

1. Загрузите код в GitHub-репозиторий
2. Откройте вкладку **Actions** в репозитории
3. Выберите workflow **«Собрать НеЗабудка .exe»**
4. Нажмите **«Run workflow»** → **«Run workflow»**
5. Подождите ~5–10 минут
6. Перейдите в завершённый запуск → раздел **Artifacts** → скачайте **НеЗабудка-Windows**
7. Внутри архива — файл `НеЗабудка Setup 1.x.x.exe`

Этот `.exe` можно распространять коллегам — он устанавливается как обычная программа.

---

## Сборка вручную (нужен Windows-компьютер)

### Требования
- Node.js 20+: https://nodejs.org
- pnpm: `npm install -g pnpm`

### Шаги

```bash
# 1. Из корня репозитория
pnpm install

# 2. Собрать .exe
pnpm --filter @workspace/desktop make:win

# 3. Готовый файл — в папке:
artifacts/desktop/release/
```

## Где хранятся данные пользователя

SQLite база данных находится на компьютере каждого пользователя:

| ОС | Путь |
|---|---|
| Windows | `C:\Users\<Имя>\AppData\Roaming\НеЗабудка\notes.db` |
| macOS | `~/Library/Application Support/НеЗабудка/notes.db` |
| Linux | `~/.config/НеЗабудка/notes.db` |

У каждого пользователя — свои заметки, данные не синхронизируются между людьми.
