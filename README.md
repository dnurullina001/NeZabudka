# 🌸 НеЗабудка

> **Умные заметки для команды ТеДо**  
> Простое, уютное и быстрое десктопное приложение для заметок — работает без интернета, хранит всё локально на компьютере.

---

## ✨ Возможности

### 📝 Заметки
- Быстро добавляй заметки — просто пиши и нажимай Enter
- Отмечай выполненные задачи одним кликом
- Редактируй прямо в списке, без лишних окон
- Расставляй **приоритеты**: 🔴 Высокий · 🟡 Средний · 🟢 Низкий
- Прикрепляй заметку к **дню недели** (Пн–Вс) — чтобы помнить, когда что делать

### 📁 Проекты
- Создавай цветные проекты для разных направлений работы
- Фильтруй заметки по проекту в боковой панели
- Назначай заметки на проект прямо при создании

### 🔒 Сейф
- Раздел для важных записей, которые не должны теряться
- Защищённое хранение заметок с заголовком и содержимым
- Отдельный от общего списка — всегда под рукой

### 🔍 Поиск
- Мгновенный поиск по всем заметкам
- Быстрый вызов с клавиатуры — без отрыва от работы

### 📊 Статистика
- Счётчик активных, выполненных и общего числа заметок — всегда виден наверху

### 🌸 Маскот НеЗабудка
- Дружелюбный персонаж-цветочек в интерфейсе
- Оживает и реагирует, когда наводишь мышку
- Делает работу чуточку приятнее 😊

---

## 💾 Хранение данных

Все данные хранятся **локально на твоём компьютере** в файле SQLite.  
Никаких облаков, никакой регистрации, никакого интернета — просто открыл и работаешь.

📂 Файл базы данных: `%APPDATA%\НеЗабудка\notes.db`

## 🚀 Установка

1. Скачай последний установщик из раздела **[Actions → НеЗабудка-Windows](../../actions)**
2. Запусти `НеЗабудка Setup 1.0.0.exe`
3. Если Windows предупреждает — нажми **"Подробнее" → "Всё равно запустить"** (это нормально для неподписанных приложений)
4. Готово! Ярлык появится на рабочем столе

## 🛠️ Для разработчиков

Приложение построено на:

| Технология | Назначение |
|---|---|
| [Electron](https://www.electronjs.org/) | Десктопная оболочка |
| [React](https://react.dev/) + [Vite](https://vitejs.dev/) | Интерфейс |
| [Express](https://expressjs.com/) | Локальный сервер внутри приложения |
| [SQLite](https://www.sqlite.org/) + [Drizzle ORM](https://orm.drizzle.team/) | Локальная база данных |
| [TanStack Query](https://tanstack.com/query) | Работа с данными во фронтенде |
| [shadcn/ui](https://ui.shadcn.com/) | UI-компоненты |
| [GitHub Actions](https://github.com/features/actions) | Автоматическая сборка EXE |

### Локальная разработка

```bash
# Установить зависимости
pnpm install

# Запустить в режиме разработки
pnpm --filter @workspace/smart-notes run dev

# Собрать EXE для Windows
pnpm --filter @workspace/desktop make:win
